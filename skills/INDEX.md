# Skills index

The twenty-five playbook skills from *Mastering Hermes Agent*, with the schedule suggested in the book. Scheduled jobs run only while the gateway is running (`hermes gateway install`); add `--deliver <platform>` to receive results on your phone. Seven more are in [`../bonus-skills/`](../bonus-skills/INDEX.md).

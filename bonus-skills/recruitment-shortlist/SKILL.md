# Applications compared against criteria you wrote first

## When to Use
When I ask for the application comparison for a role I am
hiring for.

## Procedure
1. Read the role's criteria in ~/Business/People/hiring/<role>/
   criteria.md. If there is no criteria file, stop and ask me
   to write one. Never invent criteria.
2. Read each application in the role's applications folder.
3. For each criterion, quote the evidence from the
   application, or write "not mentioned".
4. Build one table: applicants as rows, criteria as columns,
   evidence in the cells.
5. Draft interview questions for each applicant that probe the
   criteria where the evidence is thin.

## Pitfalls
- Do not score, rank, reject or recommend anyone. The table
  shows evidence; I make every judgement.
- Ignore name, age, gender, photo, nationality, religion,
  marital status and anything else not in criteria.md. Do not
  mention them in the table.
- "Not mentioned" is not "does not have". Never treat a gap
  in a CV as a negative.
- Never contact an applicant.

## Verification
Rows in the table = applications in the folder. Every filled
cell quotes the application it came from.

## Stop and Ask Me Instead When
- The criteria file is missing or vague.
- An application includes health, disability or other
  sensitive personal information. Leave it out of the table
  and tell me it was there.
- Your location regulates automated screening of applicants.
  Check the rules before using this at all.

## Approval Required
A person reads every application. The table and questions come
to me only. Never send, pay, post or delete anything without my
explicit "approved".

# Project status rules (starter file for Playbook 16)

Hermes applies these rules exactly and quotes the one that fired. Change them to suit how you work.

- **On track:** no task overdue, nothing blocked for more than 5 working days, next milestone date unchanged.
- **Attention:** any task overdue, or anything blocked (by us or the client) for more than 5 working days, or any task not in scope.md.
- **At risk:** the next milestone date will be missed at the current rate, or a milestone date has already moved.

Report any task whose due date changed since last week.
